第1小節: Box<T>

1. Box<T> は「ヒープに置く」ための最小のスマートポインタ

let b = Box::new(5);
*b          // 5   * で中身を取り出す
*b + 1      // 6

┌─────────────────┬────────────────────┐
│       型        │ 大きさ（確認済み） │
├─────────────────┼────────────────────┤
│ Box<i32>        │ 8 バイト           │
├─────────────────┼────────────────────┤
│ Box<[u8; 1000]> │ 8 バイト           │
├─────────────────┼────────────────────┤
│ [u8; 1000]      │ 1000 バイト        │
└─────────────────┴────────────────────┘

スタックに置かれるのはポインタ1つで、中身はヒープにあります。他の言語の new で作った値へのポインタに近いですが、次の点が違います。

- 所有者は1つだけです。Box を別の変数に代入すると move で、元の変数は使えません（E0382、確認済み）。
- スコープを抜けると、ヒープの中身ごと自動で drop されます。free を書く必要も、GC もありません。

--- スコープ
  ブロックの中
  drop: heap value        ← ブロックを抜けた所で、ヒープ上の値の drop が走る
--- スコープの後

メソッド呼び出しでは、自動で参照が外れます（s.len()、s.to_uppercase() がそのまま使える）。また、Box に限っては、中身を * で move して取り出せます。

let s = Box::new(String::from("hello"));
let moved: String = *s;          // s は使えなくなる

参照 &T では、この move はできません（スライスの時に見た E0507）。Box は中身を所有しているからです。

まとめ

- Box<T> は、値をヒープに置き、所  、最小のスマートポインタです。
- 再帰する型は、Box（など）で間接参照を明示しないと、大きさが無限になって作れません（E0072）。
- Box<dyn Trait>、Box<dyn Fn> で見
- Box は、中身を * で move して取り出せる、特別な性質を持っています。
